# UI Components (React + Tailwind + Lucide)

Reusable UI components built with React 19, TypeScript, Tailwind CSS, and Lucide Icons.

- `Navbar.tsx`: Top header navigation with branding, dashboard/new-project links, and active GitHub user avatar.
- `Footer.tsx`: Page footer.
- `VisibilityBadge.tsx`: Displays lock icon for private repositories and globe icon for public repositories.
- `ProjectCard.tsx`: Complete project card displaying repository links, join link toolbar with quick-copy, share triggers (LinkedIn, X, WhatsApp), and applicant review cards with Approve/Reject actions.
- `AdvisoryBanners.tsx`: Advisory notices on GitHub personal repository write-access and honour-system screening.
