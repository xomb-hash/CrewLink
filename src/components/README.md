# UI Components (React + Tailwind + Lucide + shadcn/ui)

Reusable UI components built with React 19, TypeScript, Tailwind CSS, Lucide Icons, and accessible shadcn/ui primitives.

- `Navbar.tsx`: Top header navigation with branding, dashboard/new-project links, and active GitHub user avatar.
- `Footer.tsx`: Page footer.
- `VisibilityBadge.tsx`: Displays lock icon for private repositories and globe icon for public repositories (styled with shadcn Badge).
- `ProjectCard.tsx`: Complete project card displaying repository links, join link toolbar with quick-copy, share triggers (LinkedIn, X, WhatsApp), and applicant review cards with Approve/Reject actions (built with shadcn Card, Badge, and Button).
- `AdvisoryBanners.tsx`: Advisory notices on GitHub personal repository write-access and honour-system screening.
- `ui/`: Standard shadcn/ui component primitives (`badge.tsx`, `button.tsx`, `card.tsx`, `input.tsx`, `label.tsx`, `textarea.tsx`).
