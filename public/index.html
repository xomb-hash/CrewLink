How Crewlink Works

1

Connect your repo

Sign in with GitHub and select a repository where you have administrative access.

2

Choose join mode

Choose Referral link for standard review or Screening first to require an interview or test link first.

3

Review & Invite

Review applicants by account age and public repo count. Approving sends a real GitHub invitation automatically.

Purpose-built for builders

Crewlink only connects people. It is not a chat app and does not track team performance. Once approved on GitHub, teams continue collaborating on GitHub, Discord, or WhatsApp.
