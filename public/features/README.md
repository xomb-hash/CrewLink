# Features Module

Feature pages and client-side logic for Crewlink.

- `dashboard.html` / `dashboard.js`: Owner dashboard displaying project cards, applicant lists, share options, and advisory banners.
- `new-project.html` / `create-project.js`: Form for repository selection, join mode configuration (referral or screening), and screening link inputs.
- `join.html` / `join.js`: Public join page for applicants, presenting project overview, screening tasks (if configured), and request submission.
